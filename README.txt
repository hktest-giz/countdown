MY DAY - 취침 카운트다운 & 오늘의 할 일

실행
1. index.html 파일을 Safari, Chrome 등 웹 브라우저로 엽니다.
2. 취침 시간 입력란을 눌러 원하는 시간을 설정합니다.
3. 오늘 할 일을 적고 + 버튼을 누릅니다.
4. 체크하면 완료 처리되고, ×를 누르면 삭제됩니다.

화면 크기 대응
- 데스크톱과 넓은 태블릿에서는 카운트다운 왼쪽, 할 일 오른쪽으로 배치됩니다.
- 휴대폰과 좁은 화면에서는 카운트다운 위, 할 일 아래로 자동 전환됩니다.
- 화면 너비와 높이에 따라 숫자 크기, 패널 크기, 여백이 자동으로 조절됩니다.

아이콘 및 홈 화면 추가
- 브라우저 탭에는 favicon이 표시됩니다.
- iPhone Safari에서 HTTPS로 게시된 주소를 연 뒤 공유 버튼 > 홈 화면에 추가를 선택하면 MY DAY 아이콘으로 추가됩니다.
- 홈 화면 앱에서는 브라우저 주소창 없이 독립 앱처럼 열립니다.
- Android Chrome에서도 설치 가능한 웹 앱 설정(manifest 및 service worker)을 포함합니다.
- index.html만 따로 올리지 말고 이 폴더의 파일을 모두 GitHub 저장소에 업로드해야 합니다.

저장
- 취침 시간과 할 일은 현재 브라우저의 로컬 저장소에 저장됩니다.
- 오늘의 할 일은 날짜별로 저장됩니다.
- 브라우저 데이터/사이트 데이터를 삭제하면 저장한 내용도 사라질 수 있습니다.

GitHub Pages에 게시
1. 이 폴더 안의 모든 파일(index.html, 아이콘 파일, manifest.webmanifest, sw.js 등)을 GitHub 저장소의 같은 폴더에 업로드합니다.
2. 저장소 Settings > Pages에서 게시할 브랜치와 폴더를 선택하고 저장합니다.
3. 생성된 HTTPS Pages 주소로 접속하면 탭 아이콘과 홈 화면 추가 기능을 사용할 수 있습니다.

주의
- file://로 HTML을 직접 여는 경우 브라우저 탭 아이콘은 표시될 수 있지만, PWA 설치 및 서비스 워커 기능은 HTTPS 주소에서 정상 작동합니다.
